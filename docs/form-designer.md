# 화면 디자이너와 태스크별 그룹 통제

운영 콘솔 → 화면 관리 → 정의 선택 → 화면 디자이너에서 편집합니다. 저장된 항목 표와 디자이너는 동일한 화면 정의를 사용합니다. 디자이너에서 ‘화면 항목에 적용’을 실행하면 표에 반영되고, ‘초안 저장·검증’ 후 독립 검토·게시해야 새 업무에 사용할 수 있습니다. 디자이너 취소·Escape는 미적용 변경을 버립니다.

## 편집

- 기본정보·상세정보로 시작하며 그룹을 추가·이름 변경·삭제할 수 있습니다. 그룹 삭제 시 필드는 다른 그룹으로 이동합니다.
- 선택 그룹에 문자·숫자·예/아니오·담당자 필드를 추가하거나 선택 필드를 삭제합니다.
- 필드를 드래그해 순서와 소속 그룹을 바꿉니다. 탭 표시 중에는 대상 탭에 놓아 이동할 수도 있습니다.
- 오른쪽 아래 핸들로 너비(1~3열 중 화면 열 수 이내), 높이(48px 단위, 1~5)를 조절합니다. 작은 화면에서는 한 열로 정렬합니다.
- 필드 우클릭, Shift+F10 또는 속성 버튼으로 식별자·이름·유형·그룹·크기·필수·조회 전용·담당자 선택 범위를 편집합니다.
- 앞/뒤 이동 버튼, Ctrl+방향키 이동, Shift+방향키 크기 조정을 제공합니다. 실행 취소·다시 실행과 모바일 미리보기를 제공합니다.
- 전체 그룹 표시를 나열/탭으로 전환할 수 있습니다. 그룹과 필드는 최대 20개/30개입니다.

## 워크플로우 연결

게시한 화면 버전을 워크플로우의 공통 화면 또는 태스크별 화면으로 선택합니다. 노드의 ‘할당·연결·결재·화면 설정’에서 그룹·필드 표시와 역할을 설정합니다. 화면을 변경해 게시해도 기존 워크플로우의 참조 버전과 진행 건은 바뀌지 않습니다. 신규 버전을 선택해 워크플로우를 검토·게시해야 이후 실행에 적용됩니다.

## 권한 우선순위

그룹 숨김 → 그룹 조회 역할 → 그룹 조회/입력 모드 및 입력 역할 → 필드 숨김·조회/입력·역할 → 화면 조회 전용 → 태스크 할당 순으로 제한을 합성합니다. 필드 설정으로 그룹 제한을 해제할 수 없습니다. 그룹의 입력 허용은 해당 필드의 제한을 따르도록 허용하는 뜻이며, 모든 필드를 강제 입력 가능으로 만들지 않습니다. 결재·완료 태스크는 조회 전용입니다.

서버가 숨김 그룹·필드의 값을 HTML에서 제외하고, 필드를 위조해 API로 보내도 거부합니다. 비어 있는 그룹은 탭에서도 제외합니다. 탭 전환은 키보드 방향키/Home/End를 지원하며, 다른 탭의 필수 입력이 누락되면 해당 탭을 표시합니다. 결재 단계 확장에도 그룹 통제를 복사합니다.

## 데이터 계약

SCREEN 그래프에 선택적인 `layout: {mode: sections|tabs, groups: [{key,label,fields:[{key,span,height}]}]}`를 저장합니다. 모든 필드는 하나의 그룹에 정확히 한 번 포함되어야 합니다. 기존 layout 없는 화면은 기존 방식으로 동작합니다. WORKFLOW 노드의 `group_modes`와 `group_roles`는 연결된 화면의 그룹 식별자를 참조합니다. 그룹 키·필드 중복·범위·역할 및 조직 경계를 서버에서 검증합니다. DB 스키마 변경은 없습니다.
