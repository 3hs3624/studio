# 첫 구현 인수 계획 — v0.1

코드 구현 전의 검증 명세입니다. 현재 실행 결과는 없습니다. 연결 문서: [화면](screens.md), [API](api-contract.md), [DB](database.md).

| 검증 ID | 시나리오 | 기대 결과 |
|---|---|---|
| A01 | 직원 A가 생성하고 triage 관리자→담당자 처리→직원 확인 | NEW→ASSIGNED→IN_PROGRESS→RESOLVED→CLOSED, 각 이력·감사 1회 |
| A02 | 동일 조직 직원 B가 A 티켓 ID·댓글·활동 직접 호출 | 404, 제목·작성자·내부 기록 노출 없음 |
| A03 | 다른 조직의 관리자·담당자가 검색·ID·자산 연결 호출 | 조회 차단, FK 및 서버 검증으로 교차 조직 연결 거부 |
| A04 | 허용 그룹 밖 담당자가 큐·단일 티켓 호출 | 목록 제외·단일 404 |
| A05 | 직원이 INTERNAL 댓글·우선순위·requested_by 주입 | 권한·스키마 검증 거부, 저장 없음 |
| A06 | 서로 같은 version으로 동시 전이 | 한 건 성공, 다른 건 409, 이력·outbox 각각 1회 |
| A07 | 동일 생성·댓글·전이 명령 네트워크 재시도 | 같은 키·본문은 같은 응답, 다른 본문은 409, 중복 없음 |
| A08 | 해결 내용 없는 RESOLVE, NEW→CLOSE, CLOSED→REOPEN | 거부, 상태·이력 불변 |
| A09 | RESOLVED에서 요청자가 사유 포함 REOPEN | IN_PROGRESS, 기존 담당자 유지, 사유 기록 |
| A10 | 현재 담당자의 그룹 소속 제거 | 열린 배정 있으면 거부; 재배정 뒤 제거 가능 |
| A11 | 직원이 내부 댓글·내부 대기 사유를 상세·활동·목록에서 조회 | 모든 경로에서 필터, 공개 댓글만 표시 |
| A12 | 자산·CI 접근 없는 사용자가 연결·조회 | 대상 정보 비공개, 연결 실패 |
| A13 | 워커 실패·재시작·중복 이벤트 | 재시도 상태·추적 ID, 중복 후속 작업 없음 |
| A14 | 본문 저장 뒤 감사 또는 outbox 삽입 실패 | 전체 rollback, 부분 성공 없음 |
| A15 | 페이지 이동 중 다른 조직·필터 커서 재사용 | 거부, 다른 범위 데이터 노출 없음 |
| A16 | 세션 권한 회수 후 멱등 응답 재생 | 현재 권한 재검증, 이전 민감 응답 반환 금지 |
| A17 | 쿠키 인증에서 CSRF 토큰 누락·다른 Origin | 쓰기 거부 |
| A18 | 마지막 조직 관리자 제거·자기 관리자 권한 제거 | 거부, 권한·감사 정합성 유지 |

UI는 키보드 접수·오류 포커스·409 입력 보존을 확인합니다. DB 마이그레이션 왕복·백업 복원은 DB 선정 후 실제 환경에서 실행합니다. 이 묶음은 SLA·구매·승인·CMDB 대사 기능의 인수를 대신하지 않습니다.
