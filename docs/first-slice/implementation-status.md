기능 ID별로 PLT-01/02/06/07, ITSM-01/02/04/05, AST-01/02, CFG-01, ITSM-06/07, PLT-03/04, PRC-01/02, INV-01, CTR-01의 **일부**만 구현한 상태입니다. 해당 기능 전체 완료로 집계하지 않습니다. 45개 기능 대부분은 후속 개발 범위입니다.

## 검증 기록

- SQLite 자동 테스트: 147개 중 134개 통과, PostgreSQL 전용 동시성 13개는 별도 실행 대상.
- 새 DB 마이그레이션, 스키마 변경 누락 검사, disposable DB의 desk 마이그레이션 역/정방향, 정적 파일 수집 통과.
- 실제 Chromium: 직원 로그인·접수→관리자 배정→담당자 처리·내부 댓글·해결→직원 종료 통과. 요청자 내부 댓글 비공개 확인.
- 데스크톱·모바일 화면, 관리자·자산 조회 화면 점검. 전체 접근성 인증이나 전체 브라우저 호환성 검증은 아님.
- 기존 첫 버전의 PostgreSQL CI 30개 통과를 확인했습니다. SLA 확장 53개 테스트의 원격 결과는 PR의 최신 CI를 참조하십시오.

세부 실행은 [개발 안내](../development.md), 결정은 [ADR-001](../adr/001-application-stack.md)을 참조합니다.

추가 구현의 시간 규칙·API·주기 실행 조건·제한은 [SLA 명세](../sla.md)를 참조하십시오. 브라우저에서 달력·정책 게시, 자동 적용, 시계 정지·재개와 알림 확인을 검증했습니다.

카탈로그·서비스 요청·승인 범위와 검증은 [추가 명세](../service-requests.md)를 참조하십시오. 원격 CI 결과는 PR의 최신 실행에 기록합니다.

자산 수명주기 범위·이관·역할·제한은 [자산 명세](../assets.md)를 참조하십시오.

구매·계약·재고의 범위·API·역할·제한은 [추가 명세](../purchasing-inventory.md)를 참조하십시오. Chromium에서 구매 승인·발주·분할 입고·재고 이동·출고·장비 지급/반납과 계약 잔액을 검증했습니다. 최신 PostgreSQL 결과는 PR CI에 기록합니다.

계정 중지·재활성화·명시적 세션 회수·권한 변경 세션 만료·접속 이력은 [계정 보안 명세](../account-security.md)에 구현했습니다. Workflow 정의의 초안/게시/퇴역·이력·실행 버전 고정은 [차기 개발 범위](../workflow-versioning.md)이며 아직 범용 엔진에 구현하지 않았습니다.

SSO 실제 연결은 보류하고 [임시 계정·컨테이너 HTTPS 구성](../temporary-local-access.md)을 추가했습니다. 새 설치용 계정 발급·실제 로그인 검증과 외부 서버 배포/공인 인증서 검증은 구분합니다.

외부 접속용 [Render Blueprint](../render-deployment.md)는 준비했으며 실제 제공자 계정/리소스 생성과 외부 로그인 검수는 미완료입니다.
