기능 ID별로 PLT-01/02/06/07, ITSM-02/05, AST-01, CFG-01의 **일부**만 구현한 상태입니다. 해당 기능 전체 완료로 집계하지 않습니다. 45개 기능 대부분은 후속 개발 범위입니다.

## 검증 기록

- SQLite 자동 테스트: 30개 중 28개 통과, PostgreSQL 전용 동시성 2개는 별도 실행 대상.
- 새 DB 마이그레이션, 스키마 변경 누락 검사, disposable DB의 desk 마이그레이션 역/정방향, 정적 파일 수집 통과.
- 실제 Chromium: 직원 로그인·접수→관리자 배정→담당자 처리·내부 댓글·해결→직원 종료 통과. 요청자 내부 댓글 비공개 확인.
- 데스크톱·모바일 화면, 관리자·자산 조회 화면 점검. 전체 접근성 인증이나 전체 브라우저 호환성 검증은 아님.
- PostgreSQL CI workflow를 추가했으나 원격 CI 결과는 별도 확인합니다.

세부 실행은 [개발 안내](../development.md), 결정은 [ADR-001](../adr/001-application-stack.md)을 참조합니다.
