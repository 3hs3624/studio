# Maximo IT 기능 대응표 — v0.2

기준일: 2026-11-04. 상태: 제품 설계 초안.

## 검증 경계

아래는 Maximo IT와 같은 통합 IT 관리 제품을 만들기 위한 **후보 요구사항**입니다. 일부 항목은 IBM 공식 문서로 기능 영역을 확인했으며, 행별 근거·검증 한계는 아래 표와 [근거 문서](ibm-evidence.md)에 기록합니다. 제품 기능 동등성이나 라이선스 포함 여부를 보장하지 않습니다. PLT-01/02/06/07, ITSM-02/05, AST-01, CFG-01은 [첫 구현 현황](first-slice/implementation-status.md)에 해당하는 부분 구현이며 나머지는 미구현입니다. 부분 구현을 기능 전체 완료로 집계하지 않습니다. 단계는 개발 순서이며 일정 확약이 아닙니다.

검증 시 대상 버전·에디션·모듈·문서 URL·절 제목·확인일·기본/옵션/외부 연동 구분·차이점을 행별로 추가합니다. 시작점: [IBM Maximo IT](https://www.ibm.com/products/maximo/it), [IBM Documentation](https://www.ibm.com/docs/). 이번 개정에서는 CD 문서와 9.1 릴리스 문서를 사용했습니다. CD 동작의 9.1 적용 여부는 별도 검증합니다.

지원 방식: 기본=자체 업무 기능, 설정=관리자 설정 기능, 연동=외부 시스템 연결. 모든 기능에 권한·감사·실패 처리 기준을 공통 적용합니다.

## 범위 조정과 완료 판정

- 라이선스 규칙은 초기 기명 사용자·장치 기준부터 구현하고, 코어·가상화·서브캐퍼시티 등의 복잡한 규칙은 별도 요구사항으로 평가합니다.
- FIN-01은 비용 기록·집계이며 법정 회계·세무·감가상각 엔진을 포함하지 않습니다.
- 자동 탐색 에이전트·원격 제어·실제 배포 실행은 초기 외부 도구 연동으로 제공합니다. 릴리스 관리 화면만으로 배포 실행을 지원한다고 표시하지 않습니다.
- 각 ID는 정상·권한 거부·잘못된 전이·재시도 시나리오와 검증 증거를 가져야 완료입니다.
- IBM 대응 검증과 자체 기능 인수는 별도 상태로 관리합니다. 자체 구현 완료를 IBM 동등성 검증 완료로 바꾸지 않습니다.
