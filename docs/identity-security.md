# 사용자·조직권한·보안 관리

## 화면과 책임

운영 콘솔의 시스템 관리에서 **사용자 관리**, **조직·권한 관리**, **보안 관리**로 접근합니다.

| 화면 | 경로 | 내용 |
|---|---|---|
| 사용자 목록 → 상세 | `/console/users` | 생성, 기본정보, 조직·역할, 인증·보안, 세션, 변경·개인정보 접근 이력 |
| 조직·권한 탭 | `/console/access` | 기본 역할 배정, 그룹 소속, 변경 이력 |
| 역할 목록 → 상세 | `/console/roles` | 사용자 정의 역할 생성·권한 조합·배정·회수·중지·미사용 삭제 |
| 그룹 목록 → 상세 | `/console/groups` | 그룹 생성·구성원·변경·중지·미사용 삭제 |
| 보안 정책 목록 → 상세 | `/console/security` | 설정, 적용 대상, 변경 이력, 점검 결과 |
| 내 계정 보안 | `/account/security` | 비밀번호 변경, 민감 작업 재인증, MFA 등록·해제·복구 코드 |

역할은 허용 기능의 묶음이고 그룹은 업무 처리 조직입니다. 그룹 가입만으로 관리자 권한이 생기지 않습니다.
역할 권한은 합산합니다. 각 권한의 데이터 범위는 화면에 명시된 조직/본인/담당 그룹 범위이며, 임의 조건식·거부 규칙 편집기는 제공하지 않습니다.
조직 관리자는 권한을 위임할 수 있습니다. 위임받은 관리자는 자신에게 없는 권한을 추가 위임하거나 시스템 관리자를 변경할 수 없습니다.
기본 역할은 변경·삭제할 수 없습니다. 배정 이력이 있는 사용자 정의 역할은 삭제 대신 중지합니다.
기본 접수 그룹, 구성원 또는 업무 참조가 남은 그룹은 삭제를 차단합니다. 미종료 업무가 있는 그룹은 중지를 차단합니다.

## 사용자 정보 저장 분리

| 테이블 | 저장 내용 |
|---|---|
| `auth_user` | 로그인 ID, 비밀번호 해시, 인증 계정 상태 |
| `desk_person` | 업무 참조 ID, 조직, 계정 연결, 활성·만료·세션 버전 |
| `desk_userprofile` | 이름, 성·이름, 이메일, 연락처, 사번 (Person과 1:1) |
| `desk_credentialstate` | 비밀번호 변경일, 강제 변경, 실패·잠금 상태, 암호화된 MFA 설정 |
| `desk_loginsession` | 세션 식별·시작·최근 사용·회수 상태 |
| `desk_privacyaccessevent` | 개인정보 접근자·대상·행위·시각·요청 ID |

마이그레이션 0014가 기존 정보를 전용 테이블로 옮기고 인증 테이블의 이름·이메일을 비웁니다.
배포 교체 중 이전 프로세스와의 DB 호환을 위해 Person의 예전 이름 열은 빈 값으로만 남겨 두고 모델에서 제거했습니다.
DB 트리거로 인증 테이블 및 예전 이름 열에 개인정보를 다시 넣지 못하게 합니다.
연결되지 않은 인증 계정에 개인정보가 있으면 자동 삭제하지 않고 이행을 중단합니다.
업무 참조 ID와 비밀번호 해시는 유지합니다. 기존 비밀번호의 실제 변경일은 복원할 수 없어 이행 시각을 기준으로 초기화합니다.

연락처·사번은 기본 마스킹합니다. 원문 조회·개인정보 변경에는 관리 권한과 최근 재인증을 요구하고 접근 이력을 남깁니다.
응답 재처리 캐시에는 사용자 이름·연락처 대신 참조 ID를 저장하고 요청 중 비밀번호·개인정보는 비밀키 기반 다이제스트로 처리합니다.
계정 중지 후 개인정보 파기를 실행하면 프로필을 지우고 로그인 ID를 대체하며 업무 참조 ID·감사 이력을 보존합니다.

**이 구현은 동일 PostgreSQL 내 테이블 분리입니다.** 별도 물리 DB, 별도 DB 접근 계정, 프로필 필드 암호화는 포함하지 않습니다.
조직 보안 정책 원문이 이런 추가 분리를 요구하면 별도 설계가 필요합니다.

## 보안 정책과 적용

| 정책 | 실제 적용 기능 |
|---|---|
| 비밀번호 | 최소·최대 길이, 문자 조합, 이전 비밀번호 재사용 제한, 변경 주기·사전 안내, 기존 사용자 변경 강제, 공통/유사 비밀번호 검사, 운영자 등록 유출 비밀번호 SHA-256 목록 차단 |
| 로그인 | 계정별 실패 한도·집계 시간·잠금 시간, IP/조직별 공유 DB 시도 제한, 관리자 잠금 해제 |
| 세션 | 유휴·절대 만료, 동시 세션 제한, 개별/전체 회수, 권한 변경·계정 중지 후 기존 세션 거부 |
| 계정 | 장기 미사용 제한, 신규 계정 기본 사용 기간, 사용자별 사용 종료일 |
| 관리자 접근 | TOTP MFA 필수, 허용 IP CIDR, 재인증 유효 시간 |
| 감사·개인정보 | 최소 보존 기간 하한, 필수 마스킹, 변경·접근 이벤트 보존 |

사유와 설정 버전을 제출하여 사전 검증·영향을 확인한 뒤 즉시 적용 확인을 선택합니다.
비밀번호 생성 규칙은 다음 비밀번호 설정부터, 계정·세션 정책은 다음 인증/요청부터 검사합니다.
관리자 MFA 필수는 적용 관리자 본인의 MFA 등록을 먼저 요구합니다. 허용 IP는 현재 관리자를 차단하는 설정을 거부합니다.
프록시 뒤에서 IP 제한을 사용할 때는 인프라에서 `SECURITY_TRUSTED_PROXY_CIDRS`를 정확히 설정해야 합니다.
기본적으로 임의 `X-Forwarded-For`는 신뢰하지 않습니다. 불명확한 프록시 상태에서는 IP 제한 적용을 거부합니다.

최소 8자·CSRF·비밀번호 해시·서버 권한 검사·조직 경계·개인정보 마스킹은 끌 수 없습니다.
초대 사용자는 사용할 수 없는 비밀번호로 생성하며 관리자가 1시간 유효 일회용 링크를 수동 전달합니다.
링크 토큰은 URL fragment에 두고 브라우저가 CSRF 보호 POST로 전송하여 HTTP 접근 로그의 경로에 남기지 않습니다.
직접 임시 비밀번호를 부여한 사용자는 최초 로그인 후 변경해야 합니다.

MFA 비밀은 Fernet으로 암호화하고 복구 코드는 해시로 저장하며 한 번만 표시합니다.
암호화 키는 `SECRET_KEY`에서 파생하므로 백업 복원 시 같은 키를 보존해야 합니다.
키 변경은 기존 MFA 정보의 재암호화 또는 안전한 초기화 계획과 함께 진행해야 합니다.
복구 코드는 한 번만 사용 가능하며 TOTP 재사용도 차단합니다.

## 한계와 후속 운영

- SSO 실연결은 보류 상태입니다. 현재 로컬 인증 정책을 적용하며 IdP 연동 후 책임 경계를 다시 검증해야 합니다.
- SMTP 자동 초대, 외부 유출 비밀번호 API 조회, 정책별 예외·2인 승인·예약 적용은 아직 제공하지 않습니다.
- 감사 최소 보존 정책은 삭제를 하지 않는 방식으로 충족합니다. 자동 아카이브·기간 만료 파기와 백업 보관소 정리는 별도 운영 작업입니다.
- 보안 이벤트에는 비밀번호·OTP·복구 코드·초대 토큰을 기록하지 않습니다. 인프라 로그·백업의 접근 통제와 보존은 별도로 운영해야 합니다.
- 이 기능의 통과는 조직 보안 정책 전체나 보안 인증의 충족을 의미하지 않습니다. 정책 원문과 인프라 점검이 추가로 필요합니다.

## 기존 운영 및 로컬 Docker 업데이트

동일 소스와 마이그레이션을 기존 Render/Neon 및 로컬 AP·DB Docker에 사용합니다.
배포 시 기존 계정·비밀번호와 업무 데이터는 보존하며 인증 처리 변경으로 재로그인이 필요할 수 있습니다.

로컬 PC는 최신 `feature/incident-workflow` 소스를 받은 후 기존 `.env.ap`, `.env.db`, `access/accounts.json` 및 DB 볼륨을 유지하십시오.
ZIP 방식이면 압축 파일을 별도 폴더에 풀고 소스만 기존 폴더에 덮어쓰며 비공개 설정 파일을 삭제하거나 재생성하지 마십시오.

```powershell
python deploy/local_split/control.py backup
# 최신 소스 반영 후
python deploy/local_split/control.py up
python deploy/local_split/control.py verify
```

`up`은 이미지를 다시 빌드하고 initialize 단계에서 DB 마이그레이션을 적용합니다.
계정 초기화는 기존 계정을 덮어쓰지 않습니다. DB 볼륨 삭제·다운그레이드는 데이터 손실을 유발할 수 있으므로 실행하지 마십시오.

개발 검증: 사용자 정보 분리·DB 강제, 조직 격리, 권한 상승 차단, 역할/그룹 수명, 정책 검증, 비밀번호·잠금·세션·MFA·복구·초대·캐시 개인정보 제거를 회귀 테스트합니다.
