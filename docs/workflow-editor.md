# 워크플로우 편집

운영 콘솔 → 워크플로우 관리에서 정의를 선택합니다. 정의 목록은 상단에서 접고 펼칠 수 있습니다.

1. 기본정보와 공통 화면 버전을 선택합니다. 프로세스 데이터 항목과 고급 실행 설정은 필요할 때 펼칩니다.
2. 단계 목록이나 흐름도의 상자를 선택합니다. 선택 단계 하나의 속성만 표시하며, 업무·조건·대기·API 등 유형에 필요한 설정을 표시합니다.
3. 다음 단계·반려 경로·조건 경로·합류 단계는 단계 이름으로 선택합니다. 없는 대상을 참조하는 기존 값은 경고 문구와 함께 유지합니다.
4. 화면 항목·그룹 권한을 펼쳐 숨김·조회·입력 및 역할을 설정합니다. 표시를 접거나 다른 단계를 선택해도 설정은 유지됩니다.
5. 변경 사유와 함께 초안을 저장·검증하고 기존 독립 검토·게시 절차를 진행합니다. 진행 중인 건은 기존 버전을 유지합니다.

단계 식별자를 바꾸면 직접 연결·분기 목록·시작 단계·배치 좌표의 참조도 함께 변경합니다. 단계 삭제 시 남은 참조는 자동으로 다른 단계로 바꾸지 않으며 게시 전 검증에서 확인해야 합니다. 흐름도 상자를 끌어 배치하고 Enter/Space로 선택할 수 있습니다.
