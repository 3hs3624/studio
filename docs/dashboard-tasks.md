# 대시보드 할 일 조회 범위

통합 홈과 IT서비스 현황의 ‘내가 할 일’에서 전체/부서/나를 선택합니다. 기본값은 ‘나’이며 선택은 URL의 `todo_scope`로 유지됩니다.

- 전체: 기존 업무·메뉴·데이터 조회 권한 안의 대기 업무입니다. 조직 전체 권한을 새로 부여하지 않습니다.
- 부서: 현재 소속 부서 담당자의 대기 업무입니다. 하위 부서는 포함하지 않습니다. 부서가 없는 사용자는 빈 목록과 안내를 표시합니다.
- 나: 본인에게 할당된 업무·결재입니다. 전원 처리 태스크에서 이미 본인이 처리한 경우 제외합니다.

워크플로우의 열린 업무/결재 태스크, 워크플로우에 연결되지 않은 서비스요청의 승인·배정 업무, 배정된 진행 중 장애를 표시합니다. 종료·취소된 실행 및 완료 태스크, 비활성 사용자에 대한 할당은 제외합니다. 본인이 신청한 건의 자기 결재도 제외합니다. 워크플로우에 연결된 서비스요청은 태스크로만 표시해 중복 집계하지 않습니다.

여러 담당자가 있는 태스크도 한 건으로 집계합니다. 선택 범위의 총건수와 최근 생성 10건을 표시합니다. 상세 링크에서도 기존 조회·처리 권한 검사를 그대로 적용합니다.
