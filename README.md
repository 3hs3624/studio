# Studio — 통합 IT 관리 솔루션

IBM Maximo IT가 다루는 업무 영역을 참고하여 IT 서비스·자산·구성·변경·구매·계약을 연결하는 독립 제품을 설계합니다. IBM의 공식 제품이나 제휴 프로젝트가 아닙니다.

**현재 상태: 첫 장애 관리 흐름을 실행할 수 있는 초기 버전입니다.** 일부 IBM 공식 기능 근거를 확인했으며, 전체 동등성·라이선스 포함 여부는 검증 전입니다.

직원 접수→관리자 배정→담당자 처리·해결→요청자 확인·종료를 지원합니다. 공개/내부 댓글, 자산·CI 조회·연결, 조직별 접근 제어, 역할·그룹 관리와 감사 기록을 포함합니다.

## 제품 방향

기능 전체 체계를 먼저 설계하고, 공통 플랫폼→서비스 운영→자산 수명주기→변경·구성 통제→소프트웨어·연동 고도화 순으로 구현합니다. 대표 흐름은 장비 신청부터 구매·지급·반납까지, 장애 접수부터 문제 분석·변경·해결까지입니다.

## 초기 가정

한국어 우선 웹 서비스, 단일 기업 내 다중 조직, 단일 배포를 출발점으로 합니다. SaaS 고객사 격리와 내부 설치형 배포의 동시 지원은 미확정입니다. 초기 기술 스택은 ADR-001에 기록했습니다. 성능 수치·운영 SLA·전체 일정은 확정되지 않았습니다. 공개 저장소에는 실사용자 정보·자격증명·고객사 문서를 저장하지 않습니다.

문서 기준일: 2026-11-04. 기능 변경은 대응표 ID와 인수 기준을 함께 갱신합니다.
